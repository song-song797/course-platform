# 课程项目评分平台 Logo 说明

## 设计主线

- 主方案名称：协作评分环
- 品牌气质：协作开放、清新科技、结构清晰
- 核心语义：课程项目、多人协作、结构化评分、结果汇聚

图形由三部分组成：

- 开放环形：表示评分流程流转与协作闭环
- 三个节点：表示多角色参与和多点评价
- 中央评分卡：表示 Rubric 结构化评分与结果确认

## 使用建议

- 登录页和答辩封面优先使用横版主 logo
- 侧栏、头像位、卡片角标优先使用方形品牌图标
- 深色背景使用反白版
- 单色打印、文档页眉和低成本输出场景使用单色版

## 颜色建议

- 主蓝：`#3F7EFF`
- 深蓝：`#245FD1`
- 浅蓝：`#EEF5FF`
- 正文深色：`#16324F`
